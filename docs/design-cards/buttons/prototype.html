Rules

What not to do

Each renders so the contrast reads — wrong for a specific reason.

❌ ghost Edit — borderless reads as a link. Use a real .btn or an actual <a>.
❌ small Run — one size only. For a tighter control, use a 16px icon-only affordance.
❌ two amber — the eye can't pick the action.
❌ verbose Save and continue to next step → shorten to . Buttons never wrap.
❌ radius Launch — the system is square.
