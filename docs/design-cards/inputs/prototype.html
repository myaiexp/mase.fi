Rules

What not to do

Each example renders the wrong version next to the rule it violates.

❌ glow Border shift is enough. Glow competes with focus rings elsewhere.
❌ red bg Invalid is a border + helper. Tinted bg reads like a destructive action.
❌ tall 32px breaks alignment with 22px buttons in the same row.
❌ rounded System is square. Rounded corners read as "from another design system."
❌ no label Placeholder ≠ label. It vanishes the moment a value is typed.
