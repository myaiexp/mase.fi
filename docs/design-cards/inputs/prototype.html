inputs & labels

Text input, textarea, and form label. One fixed height (22px) so inputs, selects, and buttons align in a single row. The border carries every state — no glow, no background shift, no shake.

Anatomy

Label · input · helper

Three pieces, stacked with a 4px gap. Label is micro-caps (.form-label). Helper only appears when there's something to say.

States

Empty · filled · focus · disabled · invalid

Border carries every state. Placeholder is --fg-3 (a hint, not content). Focus is an amber border; invalid is a red border plus a .helper-error line.

Rules

What not to do

Each row renders the wrong version next to the rule it breaks.

❌ glow Border shift is enough. A glow competes with the amber focus rings used everywhere else.
❌ red bg Invalid is a border + helper line. A tinted background reads like a destructive action.
❌ tall 32px breaks alignment with the 22px buttons and selects it shares a row with.
❌ rounded --radius is 0. Rounded corners read as "from another design system."
❌ no label A placeholder is not a label — it vanishes the moment a value is typed.
