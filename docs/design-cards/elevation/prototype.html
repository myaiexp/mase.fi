elevation

On AMOLED-black, a single-step bump is invisible. Elevation is structural: each layer has a named role, overlays jump two steps and add a stronger rim. No drop shadows.

The ladder

Five surfaces, one rim

Three app-level surfaces, two overlay surfaces — all shipped as tokens in base.css. Hover sits on top of any of them; it's not a layer, it's a state.

--bg #09090b Page background. AMOLED true-black.
--bg-surface #131316 Sticky headers, topbar, inline cards.
--bg-raised #18181c Inputs, buttons, raised cards.
--bg-overlay #1f1f24 Modal body. Two steps over --bg-raised.
--bg-overlay-rim #26262c Modal header / footer. One tick over the body.
In situ

Modal over content, all layers at once

Page on --bg, topbar on --bg-surface, panels on --bg-raised. The modal sits on --bg-overlay over a rgba(0,0,0,0.6) backdrop scrim that dims the app behind it — the rim and the scrim are the two separation signals.

Anatomy

The base-modal contract

The <base-modal> shadow DOM reads --bg-raised (body), --bg-surface (header/footer) and --border-color (borders). The shipped base.css selector re-points those three on the host, lifting the whole component to the overlay rung — header/footer land one tick above the body, not below it.

--bg-overlay-rim  (footer)

1px --border-overlay wraps the whole overlay — the same value draws the header and footer dividers.

/* base.css — shipped this card */
base-modal {
  --bg-raised:    var(--bg-overlay);       /* [data-content] body */
  --bg-surface:   var(--bg-overlay-rim);   /* [data-header], [data-footer] */
  --border-color: var(--border-overlay);   /* perimeter + dividers */
}
