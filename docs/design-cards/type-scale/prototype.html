The scale

Five steps · 10 → 15px

A hand-tuned dense ramp (+1 / +1 / +1 / +2), not a modular scale — the whole range is 5px. Each row is set at its own token; the px on the right is read back from the rendered element, so it stays honest.

Line-height

Two leadings · 1.4 & 1.2

Same copy, both at 12px. --leading (1.4) for any multi-line run; --leading-tight (1.2) for headings and dense single-line rows. Only two documented exceptions ship — pre at 1.3 and single-line badges at 1.
