One monospace face — JetBrains Mono — carries the entire system. Prose, labels, headings, numbers and code are all set in it; hierarchy comes from weight, --fg-* color and size, never a second typeface. Rendered live from base.css.

The face

JetBrains Mono

A humanist mono drawn for code — tall x-height, open apertures, unambiguous 0/O, 1/l/I. Picked because the fleet is code-adjacent: paths, hashes, tool output, IRC feeds.

Aa Bb Gg 0123

The quick brown fox jumps over the lazy dog — 0123456789

0 O · 1 l I i · { } [ ] ( ) < > · @ # $ & % · => -> != >=

Slashed zero, seriffed 1, tailed l, dotted i — disambiguation is the whole point.

Weights

Two files, four weights

Only Regular and Bold ship. The @font-face ranges map the in-between weights to a real file: 400-500 → Regular, 600-700 → Bold. So the on-screen step is Regular → Bold; 500 and 600 are the same pixels as 400 and 700, chosen for authoring intent.

Body, prose, meta, timestamps400 · Regular
Labels, badges, buttons, section headers500 · Regular
Nicks, subheads, active-channel600 · Bold
Headings, .bold, hard emphasis700 · Bold
Ligatures

Contextual alternates (calt)

base.css sets no font-feature-settings, so calt renders at the browser default — on. Coding sequences fuse into single glyphs. A consumer that wants a raw terminal look opts out on its own root (the mase.fi homepage does exactly this) — the shared sheet is never touched.

Numerics

Tabular figures

In a true monospace face every digit already shares one advance width, so font-variant-numeric: tabular-nums is a near no-op for JetBrains Mono itself — apply it per container, not globally, and mainly as insurance: it keeps numeric columns aligned even against the proportional fallback during the swap flash. mase.fi sets it on feed timestamps.

Fallback

Before the webfont, or if it fails
