themes — the override contract

One shipped theme: AMOLED-dark on :root. A "theme" is a consumer sheet loaded after base.css that re-declares tokens under [data-theme] on <html> — same markup, tokens only. --bg and primary text (--fg-1) are the fixed identity; everything else is a re-tintable surface.

The two right-hand panels demonstrate the mechanism — not proposed mase.fi themes.

same component markup · only :root tokens differ · --bg & --fg-1 held constant

Each panel renders the identical HTML block, injected from one template. Default is the bare base.css tokens. Accent swap overrides only the --accent family — the minimal theme; watch the primary button, focus ring, and selection follow. Frost is helm's shipped theme: surfaces, borders, secondary text, accent, and semantics all re-tint while --bg and --fg-1 stay put.
